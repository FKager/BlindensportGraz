Bestätigungscode

Für dein Konto bei Blindensport Graz soll das Passwort geändert werden. Gib zur Bestätigung diesen Code in der App ein:

{{ .Token }}

Der Code gilt eine Stunde. Wenn du dein Passwort nicht ändern wolltest, ändere es bitte trotzdem bald über „Passwort vergessen“ und sag dem Verein Bescheid: dann war jemand anderer mit deinem Konto angemeldet.
