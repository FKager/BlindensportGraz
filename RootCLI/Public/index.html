Mitglieder-Import (JSON)

Lädt eine JSON-Datei mit einem Array von Mitgliedern hoch (gleiches Format wie der App-eigene Export bzw. members.example.json). Einträge mit vorhandener id werden aktualisiert, neue Einträge angelegt; einzelne fehlerhafte Zeilen (fehlender Vor-/Nachname) werden übersprungen, nicht die ganze Datei.
